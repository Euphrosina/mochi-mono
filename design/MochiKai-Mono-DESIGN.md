## 0. 交付物与边界

## 1. 预设选型与改写声明

用户口径「可爱等宽风格的萌系手写楷」横跨三个预设，其中参数天然冲突：

| 预设 | 关键默认值 | 冲突点 |
| --- | --- | --- |
| 2 手写楷（主） | 横细竖粗 1:1.3~1:1.6、单笔渐变、起顿出锋、字势 ±1% 摆动 | 与「笔画等粗」「完全等宽」冲突 |
| 5 等宽萌系 | 前进宽度 0.6em、笔画 1:1、端头微圆、中宫大、x-height 0.65em | 与手写楷粗细对比、撇捺弧度冲突 |
| 3 萌系圆角 | 转折全圆、钩改圆点、字面率 92~96% | 与手写楷 82~88% 字面率冲突 |

**主预设选 2 手写楷**（用户点名）。以下六条为声明过的改写，同一批字内统一、不随机混用：

1. **横竖比 1:1.3 → 1:1.15**。原因：可爱风共性要求「粗细对比低、笔画等粗」，1:1.3 以上在 10px 小字里横画发灰，等宽列纹理会断；1:1.15 属低对比，不算「明显违背」共性判定。
2. **取消字势 ±1% 摆动 → 重心统一上提 1% 字高**。原因：严格等宽网格里摆动会让光标与列对齐漂移；上提 1% 同时满足可爱风「重心偏高」。
3. **单笔粗细渐变 → 仅留起笔顿，末端渐细幅度收至 ≤8%**。原因：渐变幅度大时缩到 10px 会糊、反白会崩。
4. **收笔出锋 → 圆钝短锋，方向统一右下，角度全批一致**。原因：萌系「无锐角」；但出锋方向是手写楷的身份线，不能整条删掉，否则退化成普通圆体。
5. **中宫略紧 3% → 放松 2~3%**。原因：等宽萌系要求「中宫大、开口大」，紧中宫会让「国」「日」在 0.6em 网格里腔体糊死。
6. **字面率 82~88% → 取上沿 86~88%**。原因：向萌系圆角靠拢，但不撑到 92% 以上，避免复杂字胀出 1.2em 汉字格。

保留不改：起笔有顿、撇捺有弧度、横细竖粗（弱化版）、出锋朝右下——这四条保证它是「手写楷」而不是圆体。

## 2. 规范表

| 条目 | 参数 | 依据 |
| --- | --- | --- |
| UPM / 网格 | 1000；拉丁前进宽度 0.6em（600），汉字 1.2em（1200） | 等宽硬条目：汉字正好两倍 |
| 字面率 | 86~88%，同批容差 ±3% | 六量化条目 1 |
| 笔画 / 横竖比 | 主干 88~92 单位；横:竖 = 1:1.15；同类差 ≤5% | 条目 2 + 改写 1 |
| 重心线 | 全字统一，较几何中心上提 1% 字高，容差 ±1~2% | 条目 3 + 改写 2 |
| 中宫 | 较同字号宋体放松 2~3%，容差 ±5% | 条目 4 + 改写 5 |
| 字腔留白 | 封闭腔等面积容差 ±10%，最小腔宽 ≥ 0.8×笔画宽 | 条目 5 + 萌系圆角「不糊死」 |
| 收笔与端点 | 起笔圆角短顿；收笔圆钝短锋朝右下 15~25°；横画收笔角度全批统一；转角外圆内圆，圆角半径 ≈ 0.4~0.5×笔画宽 | 条目 6 + 预设 1/3 |
| 字距 | 按外轮廓定，不按字身框；左右结构缩紧、包围结构放松；字距略松 | 补充条目 + 共性判定 |
| 拉丁度量 | x-height 0.65em（650），大写高 ≈ 1.4×x-height = 910；圆形上下超调 1~1.5% | 等宽萌系 + 拉丁四件套 |
| 行高 | 字号 1.4~1.5 倍，代码场景取 1.5 | 等宽萌系 + 编程硬条目 |

## 3. 等宽硬条目继承

- **完全等宽**：所有字符前进宽度一致，汉字 = 2×拉丁；先验「一、十、日」与字母的列对齐，再谈美观
- **歧义字符**：`0` 加斜点 / `O` 保持圆；`1` 带起笔斜切与底座 / `l` 带尾部右挑 / `I` 加上下横；`rn` 与 `m` 靠肩部转折区分
- **符号不溢出**：箭头、比较符、注释符、全角标点落在单元格内，宁可缩小不压线
- **连字**：若后续添加，只做视觉替换，前进宽度与字符组合一致；默认关闭并给两版截图
- **斜体**：若派生，结构性重画，不做整体倾斜（避免斜线字符位置漂移）
- **验收三件事**：缩进齐、光标稳、注释混排不跳格

## 4. 定调五字（骨架 → 部件比例 → 笔画处理）

按 skill 测试字集取「永、国、文、A、g」，覆盖撇捺、包围、斜画、拉丁尖顶与单层结构。**先定调，不铺满字表**。

### 永
- 骨架：中竖为轴，侧四点改作四个短圆点，重心上提 1%，不摆动。
- 部件比例：上点占字高 12%，横折与竖钩各占 1/3，左右撇捺外轮廓收在 86~88% 字面内。
- 笔画处理：起笔圆角短顿；撇捺保留弧度、末端渐细 ≤8%；竖钩改短钝圆点钩，不甩长尾。

### 国
- 骨架：外框全宽 1.2em，圆角外圆内圆；内部「玉」居中，不贴边。
- 部件比例：外框内留白 ≈ 字面 22%，中宫放松 2~3%；封闭腔面积与「日」「田」统一。
- 笔画处理：横细竖粗 1:1.15；转角圆角半径 0.45×笔画宽；末横收笔圆钝短锋朝右下，与全批同角度。

### 文
- 骨架：上点与横分离，撇捺交叉点落在重心线上，不往下掉。
- 部件比例：横占字宽 70%，撇捺展开角左右对称，外轮廓不超 88% 字面。
- 笔画处理：点做圆角短块；撇有弧度、捺末端圆钝出锋；横画收笔不方头。

### A
- 骨架：尖顶略超大写高 1~1.5% 做视错觉补偿；两腿外撇对称，横杠在 x-height 之下。
- 部件比例：横杠高度取大写高 38%，内腔三角留白与「V」「W」一致。
- 笔画处理：起笔短顿、收笔圆钝；斜画粗细按 1:1.15 归一，不出现一半方头一半圆头。

### g
- 骨架：单层结构（等宽萌系），不做双层耳；下降部收在 0.6em 前进宽度内，不压邻格。
- 部件比例：x-height 0.65em，圆形主体上下各超调 1~1.5%；下降弯钩短而钝。
- 笔画处理：曲线简化、曲率连续；与 `a` 共用同一套圆角端点规则。

## 5. 自检清单（设计阶段对照）

1. 10px 下能认清 — 待样张验证
2. 字面率 86~88%，容差 ±3% — 规范已定
3. 重心统一上提 1%，容差 ±1~2% — 已定
4. 横竖差 ≤5%（1:1.15 为声明改写，非同类笔画误差）— 已定
5. 中宫放松 2~3%，容差 ±5% — 已定
6. 字腔未糊死，最小腔宽 ≥0.8×笔画宽 — 已定
7. 标点各用本系统（中文全角居中 / 拉丁半角贴底）— 待执行
8. 反白不崩 — 待浅底深底双版样张验证
9. 节点无冗余、曲线无抖 — 待矢量阶段

## 7. 下一步（按 skill 顺序）

1. **样张**：另起「预览图」交付物。画布 2000px 宽、2 倍图、sRGB PNG；区块固定为 头部 → 字符集总览 → 字号阶梯 10/12/16/24/36/48/72（行距 1.45×）→ 段落样本（行宽 30~45 字）→ 细节特写（200~400px 高）；浅底深字、深底浅字各一版；共用一条基线与左边界。
2. **灰度稿自检**：先缩到 10px 看是否糊，糊了退回骨架，不进矢量。
3. **字体文件**：真出 `.otf` 需要矢量轮廓编译工具（如 fontTools）与逐字轮廓绘制；本 skill 只给参数，不承诺产出。授权确认后再按仓库 `build/` 流程派生，且不复制、不改编有版权的字体文件。
